\section{Introduction}
In the competitive landscape of digital advertising, optimizing marketing spend is crucial for maximizing business growth. As MAD LABS transitions into a SaaS-focused company with products like Simpala HR and Fintrack, understanding the nuances of campaign performance becomes a strategic necessity. This study utilizes marketing data from Nykaa to build predictive frameworks for Return on Investment (ROI).

\subsection{Problem Formulation}
While traditional analysis often looks at total clicks or revenue in isolation, this project takes a multidimensional approach by:
\begin{enumerate}
    \item Comparing Campaign Performance across diverse target audiences.
    \item Predicting ROI using campaign duration, engagement scores, and channel metrics.
\end{enumerate}

\textbf{Research Question:} \\
How do different campaign factors impact digital marketing ROI, and can we predict success using machine learning?

\subsection{Data Acquisition}
\begin{itemize}
    \item \textbf{Origin:} Nykaa Marketing Campaign Dataset.
    \item \textbf{Content:} Data for 55,555 campaigns including metrics for impressions, clicks, leads, and conversions.
    \item \textbf{Variables:} 18 columns covering campaign types, audience segments, and financial outcomes.
\end{itemize}

\section{Data Analysis}
\subsection{Clean and preprocess data}
The dataset was processed to ensure uniformity and model readiness:
\begin{enumerate}
    \item \textbf{Date Handling:} Seasonal features (Month, Day) were extracted to capture time-based trends.
    \item \textbf{Feature Engineering:} The number of channels used per campaign was calculated.
    \item \textbf{Categorical Encoding:} Campaign types and target audiences were converted to binary vectors.
    \item \textbf{Scaling:} Numerical features were normalized using StandardScalar.
\end{enumerate}

\section{ML/AI methods}
We used numerical features like Impressions, Clicks, Leads, and Engagement Score as predictors for the target variable: \textbf{ROI}.

\subsection{Random Forest Regressor}
The Random Forest model utilized 100 decision trees to capture non-linear relationships.
\begin{lstlisting}[language=Python]
rf_model = RandomForestRegressor(n_estimators=100, random_state=88)
rf_model.fit(X_train, y_train)
y_pred = rf_model.predict(X_test)
\end{lstlisting}

\subsection{Neural Network Model}
A Sequential API model was built with dense layers and dropout for regularization.
\begin{lstlisting}[language=Python]
model = Sequential([
    Dense(128, activation='relu', input_shape=(X_train.shape[1],)),
    Dropout(0.2),
    Dense(64, activation='relu'),
    Dense(1)
])
\end{lstlisting}
